Rule L and Forge's early tile check also refuse a tiling whose edge coarse tile is left with no points. ucla-roms ``init_coarse`` tests ``ceil((llm // 2) / np_xi)`` before it takes the surplus from the first and last tile, so 150 coarse points in 21 tiles pass its test with 8 each and leave the edge tiles with -1; ROMS-Tools cannot partition such a coarse grid, and C-Star's partitioning then retried without coarse dimensions. Edge tiles of 1 or 2 coarse points, which ``init_coarse`` runs, are still accepted.
